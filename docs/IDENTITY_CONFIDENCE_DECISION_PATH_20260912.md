## 首组关闭后的具体数学路线：恢复原物理约束，先解决计算保守性

2026-09-12，用户追问是否存在实际可行的解决办法。只读取首组已保存系数和界，没有重新训练、求LP、改U或改阈值。结果记录：`results/physical_identity_first_cal_feasibility/relaxation_witness_inspection.json`。

100个被过滤真身份的已保存删除解全部混合了多个端点，同时使用多个CE条件；这些具体 witness 不符合原冻结物理模型。完整松弛解的40个有正系数物理组中，23个存在实质端点混合，最大次要端点系数占比约52.9%。这里只统计系数结构，不将其称为谱信号质量占比。诊断比例1e-6不参与任何筛选。现有240个LP的数值证明仍然有效：问题是它们证明了外包集合的可行性，未证明原物理集合的可行性。

所以当前23TP不是物理可辨识性的已证上限。不过100个已保存替代解不合法，也不证明这100个身份均可救回；另一个合法物理解可能存在。不能把这一线索宣传成已解决40% retention。

可检验的改进是对同一有限端点U求更紧的物理全/删除界。保留 `(lipid_name,rule,channels)` 物理组及其alias绑定，每组只能选择一个完整端点，所有非nominal选择满足原共同CE条件；删除仍去掉所有同名候选的全部端点。可按共同CE枚举，再对混用端点的物理组分支。每个分支复用原LP有效上下界；只有完整覆盖的分支均被下界排除，才证明删除不可行。找到合法物理替代解则保留该见证；预算耗尽仍为UNRESOLVED。完整问题也求合法物理拟合上界，不能把一次round/refit的结果当全局最优。

这个离散表达不需要任意丰度先验。对非负端点 `a` 令 `u=a/||a||1`、`w=||a||1*x`，仅作优化变量换单位。观测L1归一后，若 `||sum(u*w)-b||1<=tau`，非负性推出 `sum(w)<=1+tau`。因此端点选择变量 `z` 的界 `w<=(1+tau)z` 有解析依据。更直接的实现可复用原LP已有的宽松有效系数界 `4/column_mass`。不改变端点谱值、生产X或数据归一化。连续放松z仍允许混合，不能声称已恢复原物理约束。

解析例子：真身份谱为(0.5,0.5)，竞争身份只允许(0.9,0.1)或(0.1,0.9)。松弛可把后两者各用一半，删除真身份后残差为0；实际只能选一个端点时，即使非负系数重新优化，最小L1残差仍为4/9。因此松弛可以拒绝原模型本来能认证的身份；此例不是当前数据已经获救的证据。

单独改进完整拟合也不能轻率承诺成功：固定当前删除下界，即使假设full上界为0，支持内最多12个真身份有非空数值判定区间；保留所需11个要求full上界严格小于1.480650186808755e-6，远低于现有0.0015248914687511666。这是使用已曝光CAL真值定位阻塞的假设计算，不是已达到的拟合、生产规则或新阈值。因此具体计算方向必须同时考虑删除侧的约束，不能只优化full残差。

下一计算若执行，应只用于同一首组的固定预算机制检验，不恢复其余五组、不需要GPU、不改变关闭的首组结论。先封存计算约束与停止规则，成功也须在新数据上验证。该数学问题只处理历史有限U下的计算；真实主线仍需条件于正确CE的最佳谱库，不把跨CE幅度当作同CE残余误差，也不能从full可拟合推断真实成分已被U覆盖。

## 最有希望的实现形式

保留 production solver 作为候选发现器；在它之后建立独立的物理身份验证层，再用独立数据校准接受规则。验证层应说明哪些观测证据无法由其他身份的合理谱变化解释，并保留弃权。最后展示给使用者的是可信个体身份、歧义/未认证、以及模型适用范围；不能把系数大小、低重建残差或一个未经校准的分数直接译为99%正确。

该形式不要求更换 ISTA，也不依赖 ISTA 的训练内部状态；更换发现器会改变报告集合，因此其端到端风险/retention仍需验证。物理竞争始终包含完整候选宇宙，不能为了增强删除必要性，只保留 solver 已报告候选。

## 第一处关键逻辑：允许模型可拟合，不等于真实组成被允许模型覆盖

如果真实组成属于允许集合，真实残差不超过epsilon，那么删除一个实际不存在的身份后，真实组成仍然可行。可靠的删除下界不可能超过epsilon。这是必要性证书排除假身份的真正依据。

但是 full_upper <= epsilon 只证明“存在一个允许解释”。它不证明该解释就是真实组成，或真实成分已被 U 覆盖。缺库成分可以被库内 surrogate 拟合；surrogate 在错误模型里依然可能必要。高质量 full fit 不能单独解决 open-set 问题。

当前 MODEL 与目标 donor 分离是正确的开发设计；有限 MODEL 端点通常并不精确包含 CAL/EVAL 真正生成端点。这个迁移误差需要被正确的误差预算覆盖，而不能通过 full fit 成功反向认定覆盖成立。

## 第二处关键逻辑：固定匹配 CE 的参考，只约束其残余失配

用户已假设 CE 匹配正确、对应参考谱最接近实测。对每个 CE 的对应库定义

    e_j(c) = a_exp,j(c) - a_lib,j(c).
    b_p = [A_lib(c) + Delta_residual(c,p)] x_p + epsilon_p.

研究对象是这个同 CE 残余，不是 a_exp(35)-a_exp(30)。不同 CE 的差分还包含 a_lib(35)-a_lib(30)，因此不能把其幅度直接当作残余误差容限。已有 CE 联合变化只能在当前冻结 pilot 中作为受控变化证据；它是否能迁移为同条件残余的方向或幅度，需要独立支持，不能默认成立。

若本轮出现可用子集，现实验证最短的衔接是复用可信配对谱，直接比较**同 CE**、同身份、同加合物、同通道定义下的对应库与实测谱；只在有可靠通道归属的部分约束联合残余。保留用户指定的最佳参考中心，不为追求结果重新选择 CE、重新找库或随意重中心化。按身份/源文件隔离训练、校准、评价。若谱用于过 production adapter 的拟合，需要独立来源或有效的已有 OOF 预测验证泛化，不能拿训练内误差充当独立误差范围。

这一步纳入下一次现实验证的数据准备，不再开一个 CE benchmark。弱峰漏采和 pixel fluctuation 继续保持现有未估计边界，不为完整性硬造噪声。当前69/391支持也不能改写为全谱库覆盖。

## 第三处关键逻辑：计算松弛可能丢失大量可认证身份

当前 full 上界来自共同 CE、每身份一个完整端点的物理可行拟合；删除下界来自更宽的 cone，允许同身份多个端点混合和跨 CE 混合。故

    d_deleted_relaxed <= d_deleted_physical.

RELAXATION_REPLACEABLE 表示外包集合可替代，不是已构造物理替代。严格的完整模型和宽松的删除模型组合可能过于保守。

已有结果中，每个身份可通过的 epsilon 区间为

    [full_upper + gamma, deleted_lower - gamma).

如果 deleted_lower - full_upper <= 2*gamma，这个区间为空，调 epsilon 不能救这个证书。最终审查可从现有证明直接统计这些空区间，以及 full 物理上界与 full 松弛拟合值的差距、删除解是否实际混用了端点/CE。它们都是既定结果解释，不改变接受规则。

若损失主要由松弛或 full rounding 的保守性导致，下一步优先解决**同一 U 的计算问题**：更好的原物理可行 full witness，以及有界分支定界/整数选择对真实删除问题给出上下界。全候选仍参与；不能只找几个近邻而声称全局证明。无需重训 GPU、改 U 或新空间权重。只在计算能得到更紧证明时认证；局部优化失败或超时均不能当作身份通过。

在已曝光病例上的计算检查只能定位原因，不能改写本轮 NO-GO 或作为新的独立性能验证。任何后续改法先封存，再用未曝光数据评价。

## 另一项可能的损失：整体容差掩盖小成分

在同一非负可行 full 解里，保持其他系数并删除身份 j，就得到一个候选删除解释。由三角不等式，删除残差上界不超过 full 残差加上 j 的信号贡献。因此较大的整体误差预算会使小贡献身份难以认证；即使该身份已经被 solver 找到，也不一定有足够的可区分证据跨过预算。

这与同分异构竞争、数值失败、松弛过宽是不同原因。可用已存 witness 的贡献与证书间隔解释，不能提升 reporting gate、删除弱真值或改分母来让40%达标。V2只关闭了它实际测试的条件平均方案，没有证明所有多观测信息无效；本轮仍不重开空间变体。

## 风险控制需要直接面对真实的困难假身份

开发/正式验证应保留真实近邻替代、库内补偿失配和真值缺库 surrogate；普通随机 decoy 不能自动代表这些错误。Scheubert等的原始谱库匹配研究已指出，缺库时相似异构体的错误 target 高分可多于 decoy，导致低 q 值风险被低估。这与本项目关心的错误机制一致，但其谱库匹配阈值不能搬到 DIA 混合解卷积。[原文](https://www.nature.com/articles/s41467-017-01318-5)

最终可将冻结的物理证据交给独立风险校准层。Learn then Test 提供将风险约束转成校准集上的检验的通用思路；选择的风险对象、独立单位和部署分布仍须匹配。共享身份/来源/模板的许多结果行不是同样多的独立实验。标准 Conformal Risk Control 的有界单调损失条件也不能直接套到通常非单调的 FDP 阈值曲线；不会因为换名就消除分布偏移。[Learn then Test](https://arxiv.org/abs/2110.01052)、[Conformal Risk Control](https://arxiv.org/abs/2208.02814)

物理最坏情况证书与统计1%风险是两个层次；目标允许有限风险，不要求所有合理世界里每个身份都必然成立。但如果未来采用概率加权而放弃最坏情况要求，需要可信的误差分布和独立风险证据，不能任意给少量 CE 端点安上概率来换 retention。

## 缺库的处理边界

任意非负 unknown spectrum 可以取为整个观测，此时所有已知身份都可删除。给 unknown 加任意惩罚也只是偏好某种解释，不是身份正确性证明。只有独立观测支持的未知谱、化学/质量约束或其他独立证据，才能让 unknown 成为可检验的扩展。

DecoID提供了一个具体先例：从数据中的较纯 MS/MS 建立 on-the-fly unknown library，用于解释缺库干扰；这依赖实际取得的谱与采集信息，不是自由残差项。它也使用可用的 MS1/保留时间信息。不能假定当前 MSI 已具备这些额外信息，不能把同一 A/B 中已有的信息重复计作独立证据。[DecoID原始论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC9302972/)

若可信物理替代在缺库挑战中仍普遍存在，才考虑最小额外信息：已有但尚未使用的独立 precursor/isotope 观测（若存在且有分辨力），或针对性较纯/窄窗/多CE MS/MS。CE参考谱不是当前组织同一成分的多CE观测。相同precursor/isotope的异构体不能靠这项证据硬分开。
