# Finite reference flexibility: bounded CPU development screen

2026-09-11. User requested an implemented response to the demonstrated mismatch problem. This is a secondary CAL-only feasibility screen, not execution of the paused six-GPU protocol in MISMATCH_CONFIDENCE_PILOT.md. Production definitions and original thresholds remain frozen.

Basis: explicitly accounting for reference spectral variability is established in adjacent unmixing research, including [DANSER](https://arxiv.org/abs/1507.01661) and [PLMM](https://arxiv.org/abs/1502.01260). These publications motivate treating the reference as imperfect; they do not validate this particular lipid confidence score. This implementation is a finite dictionary prototype, not a reproduction of either paper.

Use the already audited MILD CAL_R1_K125 observed cube and the211 molecular identities reported by pixelwise NNLS. All125 truths remain in the recall denominator. Scoring takes only the database and foreground-mean observation. Every candidate gets its original spectrum plus two independently drawn variants under the known synthetic mild/moderate perturbation family. New namespace reference_flexibility_CAL_v1/reference is disjoint from observation generation. No A_target, latent variables or truth labels generate/select the references. The fact that the perturbation family is known limits the result to model-family-matched development, not real-data uncertainty.

All1173 columns compete. Fit full nonnegative coefficients; remove every variant of every candidate column belonging to the one tested molecular identity and refit. Different lipid identities remain distinct. The score is normalized deleted-minus-full SSE, nonnegative with a prespecified1e-12 floor for this NEW score only. Original rho is unchanged. Equal flexibility does not guarantee correct discrimination, and expanding the dictionary can make identities less identifiable.

Before scoring, verify frozen input bindings, deterministic/nonnegative/unit-norm references, one-reference singleton parity, tiny exact/zero fits and deletion of all same-identity variants. Require normalized KKT diagnostics<=1e-9 and no normalized negative loss gain below-1e-10. Stop on numerical failure. Prespecified cost gate: full fit<=60s and median first8 index-ordered deletion fits<=10s. No adjustment after outcomes; retain failures and partial artifacts.

Compare this score against rho and X_hat on the SAME NNLS reported universe using tied-score CAL curves, AP/AUROC and maximum all-truth recall at empirical1%/5% FDR. Proceed to independent validation design only if the new score improves recall by at least10 percentage points over BOTH baselines at5%. Otherwise stop this version. No calibration/test transfer claim from this already examined CAL case. No immediate GPU expansion even on a positive screen. Existing missing-library challenge and V59 retain priority.
