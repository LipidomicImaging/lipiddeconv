Question: can bounded alternative-reference spectra improve individual-identity recall at calibrated low FDR beyond the observed fixed-spectrum rho and abundance baselines?

Scope: six new K125 datasets, two severities times three development stages. In each stage use the existing frozen V57 spatial/abundance assignment: DEV=CAL_R1_K125, CALIBRATION=CAL_R2_K125, TEST=HOLD_R1_K125. Preserve full391 candidate input, reporting gate, physical signal scaling and production training. The two severities retain V58 MILD/MODERATE definitions; the namespace for new observation perturbations is mismatch_confidence_pilot_v1/observation/{stage}. Reference-variant randomness uses the disjoint namespace mismatch_confidence_pilot_v1/reference. Derive seeds by the established SHA256 procedure and record them before generating new test observations. No extra K ladder or large factorial design.

The test identities were already encountered in V58 diagnosis. New random perturbations provide a fresh realization test conditional on this identity pool, NOT unseen-identity, unseen-library, experimental-MSI or independent biological validation. Identities stay CAL/HOLD-disjoint within the pilot, but that alone does not undo prior developmental exposure. No paper-grade broad generalization claim is allowed from this pilot.

Three prespecified scoring arms share the same reported candidates and truth denominators:

1. Frozen original rho_zero.
2. Original foreground-mean X_hat.
3. Alternative-reference individual-identity deletion score: construct a dictionary with the original spectrum plus one independently generated MILD and one MODERATE reference variant per candidate, using the frozen V58 perturbation mechanics. Fit nonnegative coefficients to the observed foreground-mean spectrum. Compute the full-dictionary optimum once; then remove every reference column corresponding to the tested molecular identity and refit. Normalize the residual increase by observed signal energy using the original epsilon convention. All identities receive the same reference flexibility. Never use A_target, X_true, observed perturbation latents or test labels to build/select the reference dictionary.

Arm3 asks whether the individual identity is necessary under this finite alternative-spectrum model. It is not group-rho across different lipid identities, a worst-case robustness certificate, a posterior probability, or measured spectral uncertainty. Reference variants are a restricted model of uncertainty, not a license for unconstrained per-candidate spectral correction. Removing all templates for the same identity is essential; removing only one template would test a template rather than an identity. Explicitly preserve the baseline's molecular reporting semantics for duplicate candidates.

Before learned runs, implement and pass bounded CPU tests: one-reference reduction equals the frozen individual baseline on singleton cases; complete deletion of all same-identity variants; no training/test target leakage; finite outputs and nonnegative coefficients; residual-difference accuracy and KKT diagnostics, including zero-score examples; deterministic reference hashes; shared full-fit reuse agrees with independent full fits. Compare runtimes before committing to the larger dictionary. If numerical accuracy or CPU cost is unacceptable, record a blocked pilot; do not silently relax tolerances or replace the score.

DEV is for implementation diagnosis only, with no outcome-driven sweep of reference counts/severities or feature combinations in v1. For each severity and scoring arm, use only its designated CALIBRATION case to select maximum-retention thresholds at empirical FDR5/FDR1, retaining ties. Seal every arm/domain threshold before opening either TEST outcome. If no eligible threshold exists, retain none and report FDR undefined. No test threshold selection and no replacement with descriptive envelope thresholds.
