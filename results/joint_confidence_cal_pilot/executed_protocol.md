# Joint observable confidence: fixed grouped CAL screen

2026-09-11. A separate secondary strategy, not retuning the failed finite-reference score. No new solver/rho calculation or GPU. Read only30 existing MILD/MODERATE CAL molecular tables from the audited V58 snapshot. Original HOLD outcomes are not opened. Previously seen CAL data makes this an exploratory development screen.

Model inputs are only log10(max(X_hat,1e-12)), log10(max(rho,1e-24)) and a zero-rho indicator. Standardize log inputs using TRAIN records only, add their quadratic/interaction terms, and fit fixed L2 logistic regression C=1, maxiter2000, tol1e-8, no class weights or hyperparameter search. No candidate identity, library geometry, class, severity, K, replicate, truth or spatial-template metadata enters the features. Identity is used only for splitting; labels only for training/calibration/evaluation.

Assign every molecular identity and all its repeated observations to one of5 groups by SHA256('joint_confidence_CAL_v1|'+lipid_name), first8bytes little endian modulo5. For evaluation groupf, calibrate on(f+1)%5 and train on the remaining3 groups. No identity overlaps within a rotation. One pooled model and pooled CAL threshold across severities; severity is not supplied at prediction. Select maximum retention at empirical5%/1% calibration FDR with ties intact; freeze each model/threshold before test predictions. Compare original rho and X_hat with thresholds selected on the same calibration group. Report every identity exactly once out of group, including original solver misses.

Primary screen: joint rule must achieve observed FDR<=5% in BOTH severities and improve all-truth recall by>=10 percentage points over BOTH similarly calibrated baselines in EACH severity. Otherwise stop this version. No post-outcome parameter or feature changes. All-truth/reportable recall, raw solver misses, filter losses and fold-specific results are retained. This grouping avoids repeated-identity leakage, but shared simulated cubes, previously exposed CAL outcomes, known perturbation families and dependent folds preclude an independent biological/generalization or population FDR guarantee. A positive result only justifies a separately frozen validation design.
